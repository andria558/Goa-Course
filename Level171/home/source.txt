Node.js ის REPL - ის უპირველესი მიზანია უზრუნველყოს ინტერაქტიული გარემო Javascript ის კოდის სწრაფად შესამოწმებლად, დებაგინგისთვის, გასატესტად და ეს ყველაფერი ახალი ჯს ფაილის შექმნის გარეშე.


the primary purpose of the Node.js REPL is to provide an interactive environment to quickly test, debug, and experiment with JS code without creating a file.

REPL

 - R - Read: takes your code input
 - E - Eval: runs and evaluates the code
 - P - Print: shows you the immediate result
 - L - Loop: Repeats the process and waits for more input

მოდულარობა არის პროგრამული უზრუნველყოფის დიზაინის მეთოდი, რომელიც დიდ პროგრამას ყოფს ცალკეულ, მარტივად სამართავ ფაილებად (მოდულებად), სადაც თითოეული მათგანი კონკრეტულ ფუნქციონალზეა პასუხისმგებელი. ეს მიდგომა მიზნად ისახავს კოდის სტრუქტურირებას, იცავს დეველოპერებს ერთი და იმავე კოდის ხელახლა წერისაგან და საშუალებას იძლევა, რომ ფაილები მარტივად ჩაიტვირთოს სხვადასხვა ადგილას require() ფუნქციის გამოყენებით.

დეველოპმენტის პროცესის დასაჩქარებლად, Node.js-ს მოჰყვება ჩაშენებული „მთავარი მოდულები“ (core modules), რომლებიც მისი კოდის lib/ საქაღალდეში მდებარეობს. ამ მოდულების (მაგალითად: events, util, console, process და os) იმპორტირება მომენტალურად არის შესაძლებელი require() ფუნქციაში მოდულის სახელის ტექსტური სახით გადაცემით. ბევრი ეს ჩაშენებული ხელსაწყო ერთმანეთთანაც ურთიერთქმედებს კომპლექსური ამოცანების შესასრულებლად, რაც ქმნის მყარ საფუძველს მასშტაბური აპლიკაციების შესაქმნელად საბაზისო კოდის ნულიდან წერის გარეშე.


Core Modules


რა რაის მოდულურობა:

 - განმარტება: მთლიანი პროგრამის დაყონა სხვადასხვა ნაწილებად, ფუნქციონალიდან გამომდინარე.

 - უპირატესობა: იქმნება ზრდადი, მართვადი კოდი, რომელიც ამარტივებს ლოგიკის შექმნას და ხელს უშლის შეცდომებს.

 - იმპლემენტაცია: ფაილები არის გაერთიანებული და Node - ში გვჭირდება require() ფუნქციის გამოყენება.


Node.js Core Modules


 - განმარტება: Node.js ში გვაქვს ჩაშენებული modules, რომელსაც ეწოდება Core Modules. ეს მოდულები შენახული არის /lib ფოლდერში.

 - გამოყენება: მოცემულ მოდულებს ვიყენებთ require() ფუნქციის გამოყენებით.

 - მაგალითი: const event = require('events')

 - ხშირად გამოყენებადი მოდულები: events, util, console, process, os

ode.js-ის console მოდული არის გლობალური ხიდი, რომელიც აკავშირებს თქვენს კოდს ტერმინალთან და საშუალებას აძლევს პროგრამებს გაგზავნონ ან მიიღონ ტექსტური შეტყობინებები, რაც ძირითადად დებაგინგისთვის (შეცდომების ძებნისთვის) და მონაცემთა თვალყურის დევნებისთვის გამოიყენება. ვინაიდან ეს მოდული იმეორებს ბრაუზერის კონსოლის ფუნქციონალს და გარემოში ჩაშენებულია როგორც გლობალური ობიექტი, დეველოპერებს შეუძლიათ მისი ფუნქციებით მყისიერად ისარგებლონ ნებისმიერი ადგილიდან, require() ფუნქციის გამოყენების გარეშე. იგი უზრუნველყოფს დებაგინგისთვის საჭირო ისეთ ძირითად მეთოდებს, როგორებიცაა console.log() სტანდარტული შეტყობინებების დასაბეჭდად, console.table() მასივებისა და ობიექტების თვალსაჩინო ცხრილებად ფორმატირებისთვის და console.assert() შეცდომის შეტყობინებების გამოსატანად მხოლოდ იმ შემთხვევაში, თუ მითითებული პირობა მცდარია (false).

რა არის კონსოლის მოდული?
--------------------------------------------------
* მთავარი ფუნქცია: აკავშირებს თქვენს კოდს ტერმინალთან ტექსტური ინფორმაციის მისაღებად და გასაგზავნად.
* დანიშნულება: გამოიყენება გლობალურად Node.js-ში მონაცემთა თვალყურის დევნებისა და დებაგინგისთვის.
* გლობალური წვდომა: ეს არის გლობალური მოდული, რაც ნიშნავს, რომ მისი შემოტანა require() ფუნქციით არ გჭირდებათ.

კონსოლის მთავარი მეთოდები
--------------------------------------------------
* console.log()    -> ტერმინალში ბეჭდავს სტანდარტულ ტექსტურ შეტყობინებებსა და ცვლადებს.
* console.table()  -> მასივებს ან ობიექტებს მარტივად წასაკითხ ვიზუალურ ცხრილებად აქცევს.
* console.assert() -> ბეჭდავს შეტყობინებას მხოლოდ იმ შემთხვევაში, თუ გადაცემული პირობა მცდარია (falsy).
