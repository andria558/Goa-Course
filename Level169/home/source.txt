Client (Browser)
მომხმარებელი ურთიერთობს ვებსაიტის ინტერფეისთან (UI). როცა ის აკეთებს მოქმედებას, ბრაუზერი აგზავნის მოთხოვნას (Request) ვებსაიტზე.

React (Frontend)
React არის ვებსაიტის ვიზუალური ნაწილი. ის აგზავნის HTTP მოთხოვნას backend-ზე (სერვერზე) და მიღებულ პასუხს აჩვენებს მომხმარებელს.

Express.js (Backend Framework)
Express.js იღებს მოთხოვნას React-ისგან, ამუშავებს მას, მართავს გზებს (routes) და აგზავნის პასუხს უკან. ის არის Node.js-ის ნაწილი, რომელიც ამარტივებს სერვერის შექმნას.

Node.js (Runtime Environment)
Node.js არის გარემო, სადაც JavaScript მუშაობს სერვერზე. ის ასრულებს backend ლოგიკას, უკავშირდება მონაცემთა ბაზას და ამუშავებს მონაცემებს.

MongoDB (Database)
MongoDB ინახავს და იღებს მონაცემებს. ეს არის NoSQL ბაზა, სადაც ინფორმაცია ინახება დოკუმენტებად, არა ცხრილებად. Node.js უკავშირდება მას მონაცემების მისაღებად ან შესანახად.


მომხმარებელი მოქმედებს ბრაუზერში. -> React აგზავნის მოთხოვნას Express.js-ზე. ->  Express.js ამუშავებს მოთხოვნას Node.js-ის მეშვეობით. -> Node.js უკავშირდება MongoDB-ს და იღებს მონაცემებს. -> Express.js აგზავნის JSON მონაცემებს React-ზე. -> React აჩვენებს პასუხს მომხმარებელს.
